  1. O usuário preenche o formulário.
  2. O navegador envia os dados.

  4. O Python processa os dados.
  5. O Flask devolve uma nova resposta HTML.

Perguntas frequentes

HTML é uma linguagem de programação?

Não. HTML é uma linguagem de marcação utilizada para estruturar conteúdo.

Qual é a diferença entre HTML e CSS?

O HTML define a estrutura e o significado. O CSS controla a apresentação visual.

O que é Flask?

Flask é um framework web para Python. Ele permite criar rotas, receber formulários, consultar bancos de dados e devolver páginas HTML.

Como o Flask envia dados para o HTML?

O Flask pode enviar variáveis para um template Jinja. O Jinja usa essas variáveis para gerar o HTML final.

Por que este blog não utiliza JavaScript?

Porque o objetivo atual é praticar HTML e CSS. Recursos dinâmicos poderão ser adicionados no futuro.
